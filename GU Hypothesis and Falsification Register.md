## Promotion ladder

`logged → specified → mathematically_linked → fixture_tested → independently_reviewed → empirical_candidate`

Each transition requires an immutable source/evidence record and review. A later stage never retroactively makes earlier missing data disappear. The program must preserve historical wording and classify it as superseded where necessary.
