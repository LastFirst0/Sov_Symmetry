# Sovereign Engine Work Package Q1 Release Candidate

Decision: **candidate-with-blockers**.

The offline quorum adapter, Q1 oracle, Q0 adversarial corpus, focused Python tests, Rust parity baseline, threat model, test oracle, claims register, and whitepaper are included. The candidate is suitable for review and replay within the stated fixture boundary.

Blocking items before promotion beyond the offline harness are: complete Rust schema/error/rational parity, Ed25519 public-key fixtures and lifecycle policy, durable quorum and equivocation persistence, Merkle checkpoint integration, and QG5 operational review. No production consensus or key-custody claim is made.
