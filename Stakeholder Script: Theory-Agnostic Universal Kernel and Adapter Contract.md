# Stakeholder Script: Theory-Agnostic Universal Kernel and Adapter Contract

## Intended duration: 10–12 minutes

### Opening

“Sovereign Engine has one governing role: it is a common evidence layer below theories, not a theory above them. It accepts a declared structure and a named check, then returns an inspectable receipt with a clear scope.”

### The correction

“Geometric Unity and other research programs remain valuable source material, but no framework is privileged by the evaluator. A framework identifier is provenance—where a claim came from—not a key that changes mathematics or confers credibility.”

### Proof of neutrality

“We submitted the same symmetric-matrix claim under seven labels: Geometric Unity, causal set, exceptional algebra, amplitudes/twistor, noncommutative geometry, holographic QEC, and custom research. The result was identical in every case: `verified`, with the same receipt ID. That does not say the theories are equivalent. It says our implementation does not favor a label.”

### What the kernel now checks

“The public portfolio has six bounded adapters: matrix symmetry, identity, inverse, finite partial order, undirected graph connectivity, and rank-three tensor last-index symmetry. Every one has positive, negative, malformed, and mutation behavior. The shared integration pack contains 24 cases—four for each adapter—and all 24 pass.”

### The third-party contract

“A new framework can contribute an adapter, but not a hidden worldview. It must publish a versioned predicate, typed object schema, assumptions, fixture pack, replay path, audit behavior, and non-claims. The same input must produce the same receipt under at least three provenance labels. Empirical, interpretive, and metaphysical claims are not forced into a fake verdict; they remain `unverifiable` until an appropriate external evidence process exists.”

### Assurance and limit

“Receipts can be replayed. Optional local audit attachments, Merkle inclusion proofs, and deterministic Ed25519 fixture verification add inspectability. They do not create a public transparency service, operational key management, or production consensus system. Those are separate programs.”

### Closing

“The decision rule is durable: compare claims fairly, verify structures precisely, and preserve uncertainty honestly. That makes the kernel useful to many research traditions without allowing any one of them to capture it.”
