# Theory-Neutrality Audit Report v0.1

## Scope and result

The audit examined the isolated Python kernel, Rust parity crate, command-line tools, reproducible release bundle, and program documentation. **No runtime evaluation branch uses a named theory or framework identifier to change mathematical results.** The only runtime occurrences of named frameworks are in the comparison fixture that demonstrates neutrality.

The audit found many theory-specific terms in the wider project directory. They occur predominantly in historical research, transcript analysis, early meaning-layer artifacts, slides, and research registers. These files should be retained as **archived research sources**, not deleted or silently rewritten; their status is now governed by the theory-agnostic re-baseline.

| Surface | Finding | Required handling |
|---|---|---|
| `sov_evidence_geometry_core` | No named-framework evaluator branch | Keep theory-neutral regression test |
| `tools/run_framework_comparison.py` | Seven named labels used only to prove equivalent results | Retain as neutrality evidence |
| Rust parity | Contract/data semantics, no named theory labels | No change required |
| Offline release guide/boundary | Updated with theory-neutral framing | Include in release bundle |
| Historical GU/meaning-layer documents | Theory-specific research context exists | Preserve; label archival/research, not kernel ontology |
| Public summaries | Must avoid wording that makes any framework the default | Apply correction register to future materials |

## Residual risks

A framework-neutral dispatcher alone does not make the system scientifically neutral. Bias can enter through which predicates are chosen, which data are admitted, how assumptions are stated, and which results are highlighted. Every future adapter must therefore publish its scope, fixtures, assumptions, non-claims, and claim class.

## Evidence

The same symmetric matrix claim was executed under seven labels: Geometric Unity, causal set, exceptional algebra, amplitudes/twistor, noncommutative geometry, holographic QEC, and custom research. All received `verified` with the identical receipt ID. This demonstrates **implementation neutrality for that named structural check**, not equivalence among the frameworks.
