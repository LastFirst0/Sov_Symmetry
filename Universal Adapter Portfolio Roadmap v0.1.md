# Universal Adapter Portfolio Roadmap v0.1

## Purpose

The universal kernel expands through small adapters that evaluate precise structures, not through an attempt to choose or prove a grand theory. Each adapter is a bounded bridge from a framework-independent object to a named predicate, receipt, replay bundle, and explicit non-claims.

## Current portfolio

| Adapter | Structural object | What it checks | Framework-neutral use |
|---|---|---|---|
| `matrix.symmetric.v1` | Finite numeric matrix | Equality to transpose | Any relation, coupling, covariance, or adjacency model that declares this representation |
| `matrix.identity.v1` | Finite numeric matrix | Identity structure | Any declared transform/product identity |
| `matrix.inverse.v1` | Pair of finite numeric matrices | Declared product is identity | Any bounded inverse candidate |
| `relation.partial_order.v1` | Finite binary relation matrix | Reflexivity, antisymmetry, transitivity | Any finite dependency, precedence, reachability, or causal-order candidate |

## Next admission gates

| Gate | Deliverable | Pass criterion | Non-claim |
|---|---|---|---|
| U2: Graph invariant | `graph.connectivity.v1` or an equally scoped graph predicate | Fixed fixtures, replay, and mutation evidence | Does not establish emergent spacetime or network ontology |
| U3: Finite tensor relation | A small indexed-tensor symmetry/trace predicate | Explicit dimensions, index conventions, and exact fixtures | Does not validate a physical field theory |
| U4: Data-to-claim evidence | Empirical packet descriptor | Provenance, uncertainty, protocol, and no kernel verdict without an external statistical process | Does not make data alone theory proof |
| U5: Formal bridge | Optional proof artifact binding | Theorem/source/assumptions linked to a named code predicate | Does not prove an entire runtime or framework |

## Adapter admission checklist

Every candidate must specify the object schema, named predicate, assumptions, positive/negative/malformed fixtures, receipt scope, replay behavior, audit behavior, and claim class. Theory names may appear only as provenance and source references.
