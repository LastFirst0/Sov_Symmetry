## Calculation Method

The estimates use weighted work-package closure rather than code volume. A delivered package needs an executable artifact, a bounded contract, and a passing test or release command. A planned interface, a source-only acceptance result, or a narrative specification receives partial credit; a broader interpretive claim receives none.
